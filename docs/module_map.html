모듈 의존성 지도

docs/ 22개 문서가 각 파일을 개별로 설명한다면, 이 그림은 그 파일들이 서로를 어떻게 가져다 쓰는지 한눈에 보여준다. 화살표는 "가리키는 쪽이 가리켜지는 쪽을 import한다"는 뜻이고, 아래로 갈수록 더 근본적인(다른 걸 안 가져다 쓰는) 모듈이다.

back/ — Qt 없는 순수 데이터 계층
front/ — PySide6 UI 계층
실행 진입점
화살표 = "가져다 씀" (import), 굵고 진할수록 적은 수의 대상을 가리킴

읽는 순서

위 지도에서 아래→위로 읽는 순서와 같다

back/ — 기반부터

  1. 01models.md다른 모든 모듈이 참조하는 기본 데이터 타입 (Scenario, TaskWindow, LabelDraft)
  2. 02session_loader.md원본 폴더를 스캔해 센서별 파일 목록(TrialData)을 만듦
  3. 03timestamp_index.md절대시각 ↔ 프레임/샘플 위치 변환, 정렬의 핵심 엔진 (분량 많음)
  4. 04coverage.md센서별 대략적인 커버리지를 가볍게 조회 (경고 배너용)
  5. 05audio_stitcher.md세그먼트 오디오를 재생용 연속 wav로 이어붙임
  6. 06radar_index.md레이더 seg 폴더를 스캔해 프레임 단위 인덱스를 만듦
  7. 07survey_parser.mdsurvey json → TaskWindow 리스트 (타임라인 프리필 마커)
  8. 08draft_store.md확정 전 라벨 draft를 JSON 파일에 저장/불러오기
  9. 09segment_exporter.mddraft를 실제로 잘라 최종 폴더 구조로 내보냄, back/ 대부분을 엮음
  10. 10label_taxonomy.mdDMS_Actions.xlsx → distraction 폼의 Area/Verb/Noun 목록
  11. 11video_codec.mdOS별로 실제 동작하는 mp4 fourcc를 찾는 유틸

front/ — 그 위에 얹는 UI

  1. 12stream_player.md카메라 스트림 하나에서 절대시각에 해당하는 프레임을 읽어옴
  2. 13playback_controller.md오디오를 마스터 시계 삼아 여러 스트림 재생을 동기화
  3. 14widgets_timeline_widget.md타임라인 바 위젯 — 마커, draft 구간, 재생헤드, 확대/이동
  4. 15widgets_video_panel.md영상 프레임 하나를 보여주는 패널 (6분할 그리드의 한 칸)
  5. 16widgets_label_forms.md시나리오별 라벨 입력 폼 3종 + "기타" 자유서술 위젯
  6. 17labeling_page_loader.md무거운 계산을 백그라운드 스레드에서 먼저 끝내는 로더
  7. 18export_worker.md최종 저장 배치를 백그라운드 스레드에서 돌리는 워커
  8. 19labeling_page.md시나리오 공통 라벨링 화면 — 가장 크고 많은 걸 엮는 파일
  9. 20start_page.mdhome 디렉토리/트라이얼 선택 화면
  10. 21main_window.mdStartPage → 시나리오 선택 → LabelingPage 전환을 관장하는 최상위 조립점

진입점

  1. 22entry_points.mdfront/main.py, run_app.py — MainWindow를 띄우는 두 개의 실행 스크립트
전체 22개 문서는 docs/ 폴더에 있다. 이 지도는 각 문서의 "이 파일을 가져다 쓰는 곳" 표를 모아 다시 그린 것이라, 개별 관계의 근거(어느 함수가 왜 가져다 쓰는지)는 해당 문서를 보면 된다.
